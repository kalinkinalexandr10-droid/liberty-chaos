Установка

Инструкция для Steam-версии GTA IV: Complete Edition, версия 1.2.0.59. Даунгрейд игры не нужен.

1

Найди папку игры

В Steam: правой кнопкой по GTA IV → «Управление» → «Просмотреть локальные файлы». Нужна папка GTAIV, в которой лежит GTAIV.exe. Обычно это ...\steamapps\common\Grand Theft Auto IV\GTAIV.

2

Поставь загрузчик модов

Скачай с официальной страницы и распакуй в папку GTAIV:

  • Ultimate ASI Loader — архив Ultimate-ASI-Loader.zip (не x64). Внутри один файл dinput8.dll.
  • ScriptHookDotNet v1.7.1.8 — архив scripthookdotnet_v1.7.1.8.zip. Из него нужны ScriptHook.dll, ScriptHookDotNet.asi и aCompleteEditionHook.asi.
3

Распакуй моды

Скачай полную сборку или нужные моды и распакуй архив прямо в папку GTAIV. В итоге рядом с GTAIV.exe появится папка scripts с файлами *.net.cs и папками модов.

4

Только для Windows 11: разреши загрузчик

Защита Windows «Интеллектуальное управление приложениями» блокирует dinput8.dll, и игра вылетает с «Непредвиденной ошибкой». Выключи её: «Безопасность Windows» → «Управление приложениями и браузером» → «Параметры интеллектуального управления приложениями» → «Выкл».

Учти: на многих сборках Windows 11 включить эту защиту обратно можно только переустановкой системы. Антивирус Defender продолжит работать.
5

Запусти и проверь

Запусти игру через Steam и загрузи сохранение. Нажми ~ — откроется консоль ScriptHookDotNet. Потом F9 — окно настроек модов, где можно включить русский язык.

Клавиши

КлавишаЧто делает
F5Меню транспорта. R — случайная машина.
F6Меню оружия, броня и здоровье.
F7Меню NPC: +/− количество, B драка, G охрана, H охота на тебя, N успокоить, C убрать всех.
F8Полёт: WASD, Space/Ctrl вверх-вниз, Shift быстрее, Q что сбрасывать, X сбросить.
F9Настройки: язык, цвет меню, лимиты машин и NPC, переназначение всех клавиш.
F10Меню возможностей: трафик и пешеходы, починка машины, телепорт к метке на карте, быстрое сохранение, тур по 200 голубям (End — голубь убит, к следующему).

В меню: стрелки — выбор и категория, Enter — выбрать, Backspace — закрыть.

Если что-то не работает

Что видишьЧто делать
«Непредвиденная ошибка» при запускеШаг 4: Windows блокирует dinput8.dll. Чтобы временно запустить игру без модов, убери этот файл из папки игры.
Консоль по ~ не открываетсяПроверь, что все файлы из шага 2 лежат прямо в GTAIV, а не во вложенной папке.
Меню не открываетсяОткрой ScriptHookDotNet.log в папке игры — там будет ошибка мода. Проверь, не переназначена ли клавиша в F9.
Игра зависла после Alt+TabЭто особенность самой Steam-версии GTA IV. Старайся не сворачивать игру.
