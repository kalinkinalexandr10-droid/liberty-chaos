# Сайт Liberty Chaos Pack

Сайт с инструкцией по установке и скачиванием модов. Бэкенд — Node.js + Express.

## Что умеет
- **Главная** (`/`) — карточки модов, кнопки «Скачать», счётчик скачиваний, история версий.
- **Установка** (`/install`) — пошаговая инструкция, таблица клавиш, решение проблем.
- **Админка** (`/admin`) — вход по паролю, статистика скачиваний, загрузка новой версии мода (.zip + список изменений), правка названий и описаний, удаление версий.

## Запуск
1. Установи **Node.js LTS** с https://nodejs.org (версия 18 или новее).
2. В папке `site`:
   ```
   npm install
   npm start
   ```
3. Открой http://localhost:3000. При первом запуске в консоли один раз покажется **пароль админки** — запиши его.
   Сменить пароль: `npm run set-password -- НовыйПароль`.

## Архивы модов
`tools\build-packages.ps1` собирает из папки `..\scripts` архивы в `packages\`:
```
powershell -ExecutionPolicy Bypass -File tools\build-packages.ps1
```
При первом запуске сервер регистрирует их как версию 1.0.0. Дальше новые версии загружаются через админку.

## Где что хранится
- `data/db.json` — моды, версии, счётчики скачиваний.
- `data/admin.json` — хэш пароля админки (сам пароль не хранится).
- `files/` — архивы всех загруженных версий.
- `public/` — страницы сайта.
