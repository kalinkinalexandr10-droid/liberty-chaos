# Сайт Liberty Chaos Pack

Сайт с инструкцией по установке, скачиванием модов и обратной связью. Бэкенд — Node.js + Express.
Живая версия: https://liberty-chaos.onrender.com (хостинг Render, бесплатный тариф).

## Что умеет
- **Главная** (`/`) — карточки модов, кнопки «Скачать», счётчик скачиваний, история версий.
  Анимации: ночной город на первом экране, у каждой кнопки «Скачать» своя сценка при наведении
  (машина въезжает, прицел, NPC, полёт, шестерёнки, голубь), карточки появляются при прокрутке.
- **Установка** (`/install`) — пошаговая инструкция, таблица клавиш, решение проблем.
- **Связь** (`/feedback`) — форма обратной связи: тема, имя и контакт по желанию, сообщение.
  Защита от спама: 3 сообщения за 10 минут с адреса + скрытое поле-ловушка для ботов.
- **Админка** (`/admin`) — вход по паролю; раздел «Обратная связь» (новые / все, прочитано, удалить);
  статистика скачиваний; загрузка новой версии мода (.zip + список изменений); правка описаний; удаление версий.

## Запуск у себя
1. Нужен **Node.js 18+** (в проекте есть портативный в `tools\node`).
2. В папке `site`:
   ```
   npm install
   npm start
   ```
3. Открой http://localhost:3000. При первом запуске в консоли один раз покажется **пароль админки** — запиши его.
   Сменить пароль: `npm run set-password -- НовыйПароль`.

## Версии модов
- `tools\build-packages.ps1` собирает из папки `..\scripts` архивы в `packages\`:
  ```
  powershell -ExecutionPolicy Bypass -File tools\build-packages.ps1
  ```
- `packages\releases.json` — номера и описания версий. При запуске сервер добавляет в каталог версии,
  которых там ещё нет; скачивается последняя. Новая версия: собрать архивы, дописать запись, залить на GitHub.
- Ещё можно загрузить версию вручную через админку.

## Где что хранится
- **Обратная связь** — в базе Postgres (Neon), если задана переменная `DATABASE_URL`; иначе в `data/feedback.json`.
  На Render диск временный, поэтому там обязательно нужна база.
- `data/db.json` — моды, версии, счётчики скачиваний (на Render обнуляются при перезапуске).
- `data/admin.json` — хэш пароля админки (сам пароль не хранится). На Render пароль задаёт `ADMIN_PASSWORD`.
- `files/` — архивы версий; `public/` — страницы сайта; `public/fx.js` — анимации.
- `neon.ts` — настройки проекта Neon; `.env.local` — строка подключения к базе (**секрет, в git не попадает**).

## Переменные на Render
| Ключ | Что это |
|---|---|
| `ADMIN_PASSWORD` | пароль админки |
| `DATABASE_URL` | строка подключения к базе Neon (для обратной связи) |
| `NODE_ENV` | `production` |
