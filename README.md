# CarSpawner — мод для GTA IV

Меню спавна всего транспорта GTA IV (124 модели: машины, мотоциклы, вертолёты, лодки) с фото-превью.

## Что нужно (Steam, Complete Edition 1.2.0.59)
1. **Ultimate ASI Loader** — `dinput8.dll`: https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/latest
2. **ScriptHookDotNet v1.7.1.8** (Tomasak, с aCompleteEditionHook.asi): https://github.com/Tomasak/gta4_scripthookdotnet/releases
3. Windows «Интеллектуальное управление приложениями» должно быть выключено, иначе `dinput8.dll` блокируется.

## Установка
```
GTA IV\GTAIV\
  scripts\
    CarSpawner.net.cs        <- скрипт (игра компилирует сама)
    CarSpawner\
      cars.txt               <- список: МОДЕЛЬ | Название | Категория
      images\МОДЕЛЬ.png      <- фото 512x256
```

## Управление
| Клавиша | Действие |
|---|---|
| F5 | открыть/закрыть меню |
| ← / → | категория |
| ↑ / ↓, PgUp / PgDn | выбор |
| Enter | заспавнить и сесть |
| Backspace | закрыть меню |

## WeaponMenu (F6)
Меню оружия справа на экране: все 16 видов оружия GTA IV + бронежилет, по категориям (← / →),
Enter — выдать с максимальными патронами и взять в руки. Пункт «All» — по лучшему оружию в каждый слот + броня.
Файлы: `scripts\WeaponMenu.net.cs`, картинки — `scripts\WeaponMenu\images\КЛЮЧ.png`.
В GTA IV в одном слоте одно оружие (Pistol и Combat Pistol заменяют друг друга).

## NpcSpawner (F7)
Меню по центру экрана: все 434 модели NPC из `common\data\peds.ide` в 8 категориях
(сюжетные, катсцены, мужчины/женщины по возрасту). ← / → категория, ↑ / ↓ выбор,
+ / − количество (1–50), Enter — призвать вокруг игрока, Delete — убрать всех призванных.
Список: `scripts\NpcSpawner\npcs.txt` (МОДЕЛЬ | Имя | Категория).
Вместо фото — живое превью: выбранный NPC стоит перед игроком и крутится, пока открыто меню.
Режимы для призванных: B — драка всех со всеми; G — охрана (случайное оружие, следуют за тобой,
садятся в твою машину, остальные угоняют машины и едут следом, атакуют напавших и копов при розыске); N — успокоить.

Дополнительно: в меню машин R — случайный транспорт (первый пункт каждой категории — случайный из неё);
в меню оружия пункт «Everything» восстанавливает здоровье, в категории «Armor & Health» есть отдельное здоровье.

## FlyMode (F8)
Полёт пешком: WASD по горизонтали туда, куда смотрит камера, Space/Ctrl вверх/вниз, Shift ускорение, потолок 1500 м.
Q — что сбрасывать (бомба, огненная бомба, машина, NPC), X — сбросить. В полёте и до приземления — бессмертие.

## Mod menu settings (F9)
Окно настроек всех модов (в меню паузы игры свой пункт добавить нельзя — его рисует движок):
язык EN/RU, лимит машин (1–100), лимит NPC (5–300), переназначение всех клавиш модов, сброс по умолчанию.
Хранится в `scripts\ModMenu.ini`, моды подхватывают изменения примерно за секунду.
Все меню рисуются обычным Arial (не жирным) — он же показывает кириллицу.

## Заметки
- Список взят из `common\data\vehicles.ide` (поезда исключены).
- Без фото: E109 и Marbella (вырезанные из игры модели — могут спавниться криво) и NOOSE Stockade.
- Фото — скриншоты с gta.fandom.com, только для личного использования.
- Ошибки скрипта — в `ScriptHookDotNet.log` в папке игры.
